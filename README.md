# Java Calculator (OOP & Logic) 🧮

A console-based calculator application built in Java to practice Object-Oriented Programming (OOP) principles and robust error handling.

## 🎯 About the Project

This project was developed as a practice exercise to implement basic mathematical operations using proper OOP architecture, separating business logic from console user interface interaction.

### What it does:
- Provides an interactive console menu with **Addition, Subtraction, Multiplication, and Division**.
- Encapsulates operations inside a dedicated `OperacoesNumericas` class.
- Handles division by zero gracefully using `ArithmeticException`.
- Prevents invalid menu options or non-numeric inputs from crashing the program.

## 🛠️ Concepts Practiced

- **Object-Oriented Programming (OOP):** Class design, constructors, and encapsulation (`private` attributes).
- **Control Flow:** Menu loop using `while` and operation routing with `switch-case`.
- **Exception Handling:** Using `try-catch-finally` to manage execution flow and resource closure (`Scanner`).
